¿Qué es el software?

    
Es el conjunto de instrucciones que le dice a una máquina qué hacer.

    
El hardware es lo que puedes tocar: la pantalla, el procesador, los cables. El software es lo que no: la app del banco, el sistema operativo, un videojuego. Sin software, una computadora es solo un objeto caro que no sabe hacer nada.

Los inicios históricos

    
     
  
    

    



    
  
    
    
    La evolución del código
    
    
    
      
    Bajo nivel
    En los años 50 se usaba lenguaje ensamblador: instrucciones casi idénticas a lo que entiende el procesador. Poderoso, pero muy difícil de leer.
    
      
    Alto nivel inicial
    Fortran (1957) y COBOL (1959) trajeron palabras parecidas al inglés. C (1972) permitió escribir sistemas operativos enteros sin usar ensamblador.
    
      
    Modernos
    Java y C++ popularizaron la programación orientada a objetos. JavaScript y Python hacen posible crear aplicaciones web y de datos rápidamente.
    
    
    
  
    

    



    
  
    
    
    El impacto de Internet
    
    
    En 1989 Tim Berners-Lee propuso la World Wide Web. Desde entonces el software dejó de vivir aislado en cada computadora: se actualiza solo, se comparte y se usa desde cualquier dispositivo.
    
    
      
      
    • SaaS: el software como servicio, que se usa desde el navegador (Google Docs, Canva).
      • 
      
    • Nube: los datos y programas están en servidores, no en tu equipo.
      • 
      
    • Apps móviles: desde 2007, con el smartphone, el software cabe en el bolsillo.
